RESUMO:

git init
- Inicia um novo projeto com git.

git add <nome-do-arquivo>/.
- Adiciona os arquivos que estão prontos para serem commitados.

git commit -m "mensagem commit"
- Commita os arquivos no histórico.

git log
- Mostra os ultimos comiits, log de alterações.

git status
- Como está o estado da nossa ramificação.

git diff
- Mostra o que foi alterado.
- O que tem de diferente na ramificação.

git merge
- Mescla ramificações.

git branch
- Mostra a branch atual.

git branch -b <nome-da-branch>
- Cria uma nova branch a partir do histórico da branch atual que estamos.

git ckeckout <nome-da-branch>
- Muda pra essa branch.

git remote add <nome-repositorio> <url>
- Adiciona um novo repositório remoto.

git push <nome-repositorio> <nome-da-branch>
- Manda nossas alterações locais para o repositório remoto, pra cada branch.

git pull <nome-repositorio> <nome-da-branch>
- Pega as alterações do repositório remoto e joga pra nossa máquina.

git fecth
- Atualiza o novo histórico local de acordo com o histórico salvo no repositório remoto.
- Sincronização do local com o remoto.
